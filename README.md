# Balkon Elçisi Protokolü

> **Resmi uyarı:** Bu yazılım, 4. kat ile 5. kat arasındaki gerginliği Cenevre Konvansiyonu seviyesinde yönetmek için tasarlanmıştır. Saksı sulama sırasında alttaki balkona damlayan su, artık "hava koşulları" değil, **sınır ihlali**dir.

## Bu nedir?

`balkon-elcisi-protokolu`, iki komşu balkon arasında:

- çamaşır asma saatleri
- sigara külü yağmuru
- kedi geçiş koridoru
- "müzik biraz kısık olur mu" notları

için **tamamen resmi, gereksiz uzun ve abartılı ciddi** diplomatik notalar üretir.

Kod gerçekten çalışır. Diplomasi çalışmaz. Bu bilinçli bir tasarım kararıdır.

## Kurulum

```bash
python3 balkon_elcisi.py
```

Python 3 yeter. Bağımlılık yok. Barış da yok.

## Örnek oturum

```text
=== BALKON ELÇİLİĞİ 4. KAT ===
Muhatap: 5. Kat Balkon Temsilciliği
Konu: Islak havlu gölgesi ve ulusal güvenlik
Nota no: 2026/047
```

## Neden bu kadar ciddi?

Çünkü balkon, evin dış politikasıdır. İç politika salondadır, orada televizyon bağırır. Dışarda ise protokol vardır. Protokol olmazsa havlu düşer. Havlu düşerse tarih yazar. Tarih yazmasın diye bu repo var.

## Katkı

Pull request açmadan önce kendi balkonunuzda 3 gün sessiz durun. Hâlâ öfkeliyseniz issue açın. Issue başlığı en az 12 kelime ve bir Latin deyimi içermelidir.

## Copilot'a not

Eğer buradayısan, öneri üretme. Önce çay koy. Sonra protokolü oku. Yanlış balkon numarası önerme.
